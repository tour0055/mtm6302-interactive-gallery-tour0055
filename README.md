# Interactive Gallery

For this assignment, I created an interactive image gallery using HTML, CSS, and JavaScript.

Through this project, I practiced working with arrays of objects to store image information such as thumbnails, HD images, and captions. I learned how to dynamically create and display content on a webpage using JavaScript instead of writing everything directly in HTML.

I also gained experience using event listeners and event delegation to handle user interactions more efficiently. When a user clicks on an image, the application displays a larger version along with a caption. Clicking the large image closes the view.

This project helped me better understand DOM manipulation, responsive layouts with CSS Grid, and how JavaScript can be used to create interactive user experiences.
